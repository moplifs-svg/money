Money Mod - Minecraft 1.20.1, Forge 47.4.28

Build:
  1. Copy gradlew, gradlew.bat and the gradle/ folder from the official Forge 1.20.1 MDK into this project
     (Gradle 8.1.1 wrapper), or use your own Gradle 8.x with Java 17.
  2. Run:   ./gradlew build
  3. The jar appears in build/libs/moneymod-1.0.0.jar - put it in your mods folder.

Items: moneymod:money_5, moneymod:money_10, moneymod:money_100  (creative tab "Money Mod")
Example: /give @p moneymod:money_100 16
